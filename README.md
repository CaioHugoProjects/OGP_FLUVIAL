# OGP_FLUVIAL
O OGP Fluvial foi projetado como uma Single Page Application (SPA), oferecendo uma experiência de navegação rápida e sem recarregamento de páginas. O foco central do sistema é garantir a segurança da informação, prevenindo fraudes internas e erros operacionais através de um rigoroso controle de acesso baseado em perfis
